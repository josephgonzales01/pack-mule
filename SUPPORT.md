# Support

Thanks for using Pack Mule! Below are the right channels depending on what you need.

## Documentation

- **README** — overview, install, and usage: [README.md](README.md)
- **Solution design** — architecture and internals: [src/main/resources/docs/SolutionDesign.md](src/main/resources/docs/SolutionDesign.md)
- **Contributing** — building, testing, and submitting changes: [CONTRIBUTING.md](CONTRIBUTING.md)

## Questions & How-To

Open a **[GitHub Discussion](https://github.com/josephgonzales01/pack-mule/discussions)** for:
- "How do I add a custom capability?"
- "How do I override templates for my org?"
- General usage questions.

Discussions are the fastest way to get help and help others.

## Bugs & Feature Requests

Open a **[GitHub Issue](https://github.com/josephgonzales01/pack-mule/issues/new/choose)** and pick the matching template:
- 🐛 **Bug report** — the tool crashed or generated the wrong output.
- ✨ **Feature request** — a new trigger, capability, or TUI improvement.

## Security vulnerabilities

Follow the private reporting process in [SECURITY.md](SECURITY.md). **Do not** open a public issue for security problems.

## Community etiquette

- Search existing issues/discussions before posting.
- Include Pack Mule version, OS, and Java version.
- Be kind and patient — this is a community project maintained in spare time.
